# Narrative Portal — variants

Structurally distinct variants of [`composition.md`](composition.md). Interpretive operational
guidance; structure only, no visual styling. Variants must differ in structure (dominant region,
ordering, split, navigation, drill-down, density, sequence, or responsive transformation), not in color,
spacing, radius, shadow, typography, or accent.

## Editorial Story

### Best for
A single narrative read start-to-finish (a story, explainer, or announcement).

### Structural model
One readable linear column with a strong opening, sequenced messages, and an onward action at the end
(and optionally mid-flow).

### Dominant element
The narrative content in reading order.

### Regions
Narrative opening · key messages (sequenced) · supporting evidence inline · onward action.

### Navigation
Linear scroll; minimal chrome; onward action at natural stopping points.

### Responsive behavior
Desktop: constrained readable column. Tablet/mobile: same single column, generous type, sticky onward
link if long.

### Distinction from other variants
Purely linear and single-threaded — no section switcher or metric-led summary; reading order is the
structure.

### Risks
Long reads losing the onward action; repeat or sticky it.

### Avoid when
The page must summarize several initiatives (Initiative Overview) or lead with outcomes/figures (Impact
Report).

## Initiative Overview

### Best for
Introducing an initiative/programme with several themes or sub-areas and multiple onward paths.

### Structural model
An opening summary followed by sectioned themes (each a genuine choice/destination) with anchored
navigation; onward actions per theme.

### Dominant element
The message plus the set of themed onward paths.

### Regions
Narrative opening · themed sections (genuine choices) · supporting content · anchored section nav ·
onward actions per theme.

### Navigation
Top nav + in-page anchors; sections are navigable destinations; each theme has its own onward action.

### Responsive behavior
Desktop: sectioned with anchor nav. Tablet: anchors collapse to a menu. Mobile: stacked sections;
anchors become a jump menu.

### Distinction from other variants
Multi-section with anchored navigation and multiple onward paths — where Editorial Story is a single
linear read. Cards, if used, are for genuinely distinct themes only.

### Risks
Sections turning into a uniform card grid; ensure sections are distinct destinations, not identical
tiles.

### Avoid when
There is one story to tell (Editorial Story) or the point is outcomes/results (Impact Report).

## Impact Report

### Best for
Communicating results and outcomes to the public, where a few figures carry the message.

### Structural model
A narrative frame with illustrative impact figures/callouts supporting the story (not a dashboard),
leading to an onward action.

### Dominant element
The narrative-plus-impact message.

### Regions
Narrative opening · impact figures/callouts (supporting, illustrative) · explanatory content · onward
action.

### Navigation
Mostly linear with optional anchors to result areas; onward action prominent.

### Responsive behavior
Desktop: narrative with impact callouts in the flow. Tablet/mobile: callouts reflow inline within the
single column.

### Distinction from other variants
Uses impact figures as *illustrative support* inside a narrative — deliberately not an Analytical Canvas
or KPI wall; figures never become the dominant, interactive element.

### Risks
Figures drifting into dashboard territory; keep them illustrative, labeled, and subordinate to the
narrative.

### Avoid when
The figures are actually an interactive data product (use Analytical Canvas), or there are no meaningful
outcomes to report (Editorial Story).
